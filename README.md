# Personal Budget & Expense Tracker

## Project Overview
This is a Personal Budget & Expense Tracker web application built as part of the Power Learn Project (PLP) Web Development curriculum.

## Progress Updates

### Week 1: Static Skeleton
- HTML structure with basic headings and form sections.
- Basic CSS styling.

### Week 2: Advanced Layout & Styling Upgrade
- **Structured Table:** Replaced placeholder text with a full <table> displaying Name, Amount, Category, and Date.
- **Form Upgrade:** Added <select> category dropdown with 5 options, date input, proper <form> container, and unique IDs.
- **Multimedia:** Added an <img> logo and embedded a YouTube video using <iframe>.
- **Interactivity:** Added collapsible <details> and <summary> element and row hover effects.
- **Advanced CSS Selectors:** Implemented descendant, direct child, position-based, focus, and negation selectors.

## How to Run Locally
