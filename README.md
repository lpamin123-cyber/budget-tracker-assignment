# Personal Budget & Expense Tracker

## Project Overview
This is a Personal Budget & Expense Tracker web application built as part of the Power Learn Project (PLP) Web Development curriculum.

## Current Progress (Week 1 - Static Skeleton)
- **HTML Structure:** Semantic structure including header, 'Add Expense' form section, and 'Your Expenses' list placeholder.
- **CSS Styling:** Basic layout styling using Element, Class, and ID selectors.
- **DevTools:** Explored inspecting DOM elements and modifying dynamic CSS properties live in browser DevTools.

## How to Run Locally
1. Clone this repository:
   git clone https://github.com/lpamin123-cyber/budget-tracker.git
2. Navigate into the directory and open index.html in your web browser.
